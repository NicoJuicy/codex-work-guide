# Repository instructions

This repository contains a concise Chinese guide to using Codex for management and knowledge work.

- Keep the main guide concise, practical, and easy to scan.
- Preserve command names, Skill names, URLs, file paths, dates, numbers, and attribution.
- Prefer plain Chinese. Avoid promotional language, empty summaries, and unnecessary examples.
- Verify time-sensitive Codex features against official OpenAI documentation before changing the guide.
- Treat copied third-party Skills as vendored code. Preserve their licenses and attribution.
- Never add credentials, private company information, or unredacted personal data.
- Do not publish, send, delete, or change external systems without explicit authorization.
